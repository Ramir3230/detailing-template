# Демо под студию

Демо — главная и Kontakt реальной студии на шаблоне: ссылка для первого сообщения ей.
Решения владельца и почему так — ROADMAP, «11. Демо под студию». Коротко:

- данные демо — в `demos/<студия>/`: своя история в git, приватный
  `Ramir3230/detailing-demos`. В шаблон и его git реальные студии не попадают;
- залитое демо — замороженная сборка шаблона из `main` в своём проекте Vercel
  `<студия>-demo`; правки шаблона его не трогают, пока его не залить заново;
- страниц групп и O nas в демо нет; кадры до/после и машина — от Afterdark, фиолетовое на
  них перекрашивается в цвет студии; фото входа — своё;
- услуги, цены, контакты, часы, рейтинг и отзывы — настоящие, студии.

## 1. Материалы от владельца

Одним сообщением спросить то, чего ещё нет:

- ссылка на карточку студии в Google Maps;
- прайс: услуги и цены — по классам авто, «od» или фиксированные; длительность, если
  студия её называет;
- откуда взять цвет: логотип, оформление прайса, вывеска;
- фото входа студии, если есть.

Чего нет в материалах — вопрос владельцу, а не догадка: выдуманная цена или часы в демо
для этой же студии хуже пустого места. Материалы кладутся в `demos/<студия>/source/`.

## 2. Заготовка

`npm run demo:new -- <студия>` — имя латиницей через дефис по названию студии:
`auto-spa`. Оно же станет адресом `auto-spa-demo.vercel.app`. В
`demos/<студия>/studio.ts` всё студийное — в [квадратных скобках], и `npm run check:data`
не пропустит ни одной пометки, цены 0 или рейтинга 0.

## 3. Данные

Поля — `content/types.ts`, образец заполнения — `content/studios/afterdark.ts`.

- `name`, `logo` (надпись — короткое имя), `meta`, `hero.subtitle`, `hero.lead` — до 120
  знаков, держит тест. `tagline`, `logoCaption`, `carClasses`, `hero.title`, `hero.car` —
  от Afterdark, если владелец не скажет иначе.
- `phone` — `+48…` без пробелов. `messengers` — только те, что студия указывает сама:
  WhatsApp и Telegram по номеру, Instagram по имени. Имя Instagram не угадывать.
- `address`: улица и номер, район; `routeUrl` — ссылка «Trasa» из карточки Maps.
- `hours` — из Maps, с понедельника; выходной — `null`.
- `rating` — звёзды, число отзывов и ссылка на отзывы из Maps. `reviews` — 3–5 отзывов из
  Google дословно, `source: "google"`, автор — как подписан; не переводить.
- `services` — группы и услуги по прайсу студии. Цена — один из видов `Price`: `byClass`
  (S, M, L; у XL всегда «indywidualnie»), `fixed`, `from`, `individual`. Цена, которая не
  ложится ни в один вид, — вопрос владельцу. Длительность — только если студия её
  называет. Пары до/после — `pair("<группа Afterdark>")` на подходящую услугу: главная
  показывает первую пару каждой группы, не больше четырёх; пара, которую не видно на
  главной, тестом не пропускается.
- `priceNote` — как студия считает цену, по её прайсу; сведений нет — спросить.
- Русский — у каждого текста `ru`: на «вы», термины русского детейлинга (полировка,
  керамика, химчистка, чернение шин), марки и адрес как есть. Заголовок hero по-русски —
  не перевод, а призыв, как у Afterdark: слово до 7 знаков, две строки.

## 4. Цвет

- Акцент — из материалов студии; `bg`, `fg`, `muted` — тёмная база шаблона. Тест данных
  требует `fg`, `muted` и `accent` к `bg` от 4,5:1: берётся светлый вариант цвета студии.
- Перекраска фиолетового:

      python scripts/recolor/recolor.py --accent "#rrggbb" --out demos/<студия>/public --sheet demos/<студия>/source/recolor.png

  Фиолетовое сейчас только на машине hero. Золото, белый и серый сдвигом оттенка не
  получаются — тогда вопрос владельцу. Неон, кнопки и свечения красит тема сама.

## 5. Фото входа и карта

- Фото входа от владельца — 4:5, от 1040×1300, `ai: false`. Нет — кадр ИИ: JSON по
  образцу `scripts/before-after/wejscie.json` в `demos/<студия>/source/wejscie.json`,
  `"out": "kontakt/<студия>"`, цвет студии в промпте. Сначала лист кандидатов
  (`--candidates 4 --preview <папка>`) — выбрать с владельцем, потом кадр:

      ~/.cache/sd/venv/Scripts/python scripts/before-after/generate.py demos/<студия>/source/wejscie.json --public demos/<студия>/public

  Вывеску с названием нейросеть не напишет: кадр без вывески, `ai: true`.
- Карта: `{ "center": [широта, долгота], "zoom": 15 }` по адресу из Maps в
  `demos/<студия>/source/<студия>.json`:

      python scripts/map/render.py demos/<студия>/source/<студия>.json --out demos/<студия>/public/mapa

  Скрипт печатает поле `address.map`.

## 6. Проверить локально

    npm run demo:use -- demos/<студия>
    npm run check:data
    npm run dev
    npm run demo:use -- --reset

Глазами — телефон 390 и десктоп 1440: главная, Kontakt, `/ru`. Пока демо стоит, шаблон
не коммитить — `git status` покажет `content/studio.ts`; `--reset` — до любой работы с
шаблоном. **Стоп:** тема, лист перекраски и фото входа — владельцу, со снимками.

## 7. Залить и открыть

- `npm run demo:deploy -- <студия>` — шаблон из `origin/main` во временной копии, данные
  поверх, `npm run check`, сборка на Vercel без открытого адреса. Её ссылка закрыта
  логином Vercel — по ней смотрит владелец. **Стоп:** его «да».
- `npm run demo:deploy -- <студия> --open` — та же сборка на адрес проекта; скрипт сам
  проверяет 200 без логина и `noindex`.
- В `demos/` — коммит данных, `public/`, `source/` и `deployed.json`. Пуш в `main`
  репозитория демо — через guard-форму, как любой `main` (CLAUDE.md папки проектов).
- Ссылку студии отправляет владелец, не Claude.

Ревьюер шаблона демо не нужен: в нём нет кода шаблона, данные проверяет `npm run check`
при заливке. Правка самого шаблона ради демо — обычная работа над шаблоном: ветка, блок,
ревью, `main`.

## Обновить или убрать

- Обновить до свежего шаблона или поправить данные — шаги 6–7 заново. Открытое демо
  меняется только после `--open`; до него в `deployed.json` записаны обе сборки.
- Студия отказалась — с согласия владельца удалить проект (`vercel project rm
  <студия>-demo`) и папку демо.
